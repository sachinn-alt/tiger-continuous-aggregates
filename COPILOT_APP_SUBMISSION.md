### Description
```markdown
### 🏰 The Lost Citadel of Aethelgard: CLI RPG Adventure Game Built with GitHub Copilot

Built an interactive, branching **"Choose Your Own Adventure"** command-line RPG game using **GitHub Copilot** as an intelligent pair programmer to generate narrative decision trees, combat mechanics, and class architectures!

#### 🎮 What Was Built:
1. **Interactive Branching Storyline**:
   - Designed a state-machine narrative exploring the ruins of Aethelgard with multiple paths (Citadel Gates, Sunken Crypts, Wandering Outpost).
   - Features 3 distinct victory endings (*The Legendary Dragonslayer*, *The Dragon Whisperer & Sage*, and *The Phantom Infiltrator*) plus custom game-over states.

2. **Dynamic Turn-Based Combat Engine**:
   - Built tactical combat systems featuring: basic strikes, mana-based class special abilities, guarding (50% damage reduction), and consumable potions.
   - Dynamic damage formulas with critical hit multipliers and varied enemy encounters (Stone Gargoyle, Crypt Warden, and Dreadwyrm Ignis).

3. **Character Classes & Inventory**:
   - 3 classes: **Vanguard Warrior** (high defense & Shield Bash), **Arcane Sorcerer** (high burst Pyroblast), and **Shadow Rogue** (agile Backstab).
   - Inventory system supporting consumables and quest relics (*Sun Rune*, *Dragon Eye Crystal*) that unlock alternative peace covenants.

4. **Terminal Aesthetics**:
   - Designed rich ASCII art banners, typewriter narrative pauses (`slow_print`), and vibrant ANSI color formatting with zero external runtime dependencies.

5. **Automated Unit Testing**:
   - Built a comprehensive unit test suite in `tests/test_game.py` verifying combat damage calculations, item healing, and narrative node graph integrity.

#### 🤖 How GitHub Copilot Was Leveraged:
- **Architecture Scaffolding**: Prompted Copilot to structure modular files (`character.py`, `story.py`, `engine.py`, `ui.py`).
- **Narrative & Lore Generation**: Prompted Copilot to generate rich fantasy descriptions, encounter dialogues, and linked choice trees.
- **Combat Formula Balancing**: Co-authored damage mitigation calculations, critical strike rolls, and enemy AI turns.
- Full prompt logs are documented in the repository's `PROMPTS.md`.

#### 🛠️ Tech Stack:
- **Python 3** (Standard Library, Dataclasses, Unitest)
- **GitHub Copilot** (Prompt Scaffolding, Inline Chat, Code Generation)
- **Git & GitHub**
```
